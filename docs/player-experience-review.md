# 玩家体验与交互边界

更新日期：2026-09-14。本轮围绕减少无关提示、降低交互步骤和保留操作后果开展重构。

## 当前行为

| 环节 | 玩家看到的内容与操作 |
| --- | --- |
| 首页 | 有保存房间时优先重返，新建/加入可展开；正常状态不常驻入口清理机制说明 |
| 等候室 | 房间码、邀请链接、准备人数和开局条件；房主准备后突出开始游戏；规则按需展开 |
| 棋盘 | 顶部展示回合、计时及玩家现金；底部集中展示当前行动；最近结果采用两行紧凑播报 |
| 本人决策 | 购买、升级、选卡、选地和未提交竞拍及时展开；价格、余额、底价和超时后果就近说明 |
| 旁观 | 默认保留棋盘，当前行动旁可主动查看；普通结果与旁观信息不抢资料面板的焦点 |
| 普通结果 | 收租、缴税、道具、卡牌结算等不弹阅读窗口，不等待固定的 8～14 秒；完整记录进入动态 |
| 对子 | 行动结束后直接“再掷一次”，执行前仍可管理资产或使用道具；第三次对子入狱规则不变 |
| 资产 | 列表显示现金、净值、资产状态和快捷管理按钮；进入详情后返回原列表并恢复持有人、滚动位置与焦点 |
| 筹款 | 显示欠款、差额和收款方；在资产列表逐级卖房、抵押，现金足够后付款；破产保留确认 |
| 道具 | 只展示持有道具，先选目标/点数或确认放置地点，再使用；显示拦截、炸弹送医和行动额度后果，完整规则可展开 |
| 历史 | 按回合分组并筛选；打开时保留当前记录，新的记录通过“查看新动态”更新，避免持续插入打断阅读 |
| 投降与暂离 | 入口在对局菜单，投降/破产保留确认；通用弹窗不再注入投降按钮 |
| 结算 | 显示赢家、排名、时长、个人数据和本局亮点；可回看动态、重开或返回首页 |

## 动画与实时状态

- 掷骰、移动、陷阱和送医仍保持顺序，关键动画结束后才开放后续操作；普通结果只占用短暂事件推进，不再设置阅读等待。
- `useGamePresentation` 与 3D 棋盘共用 `SceneRenderLoop`，依据同一开始时间计算移动进度。保留棋盘模型和物理骰子；转盘已改为 SVG 八格平面动画，并支持减少动态效果。
- 播放时可跳到当前操作；切回前台或重连直接恢复最新棋盘。实际回合计时始终由服务端控制。
- 历史随公开快照保留最近 300 条；房间仍只保存在服务端内存中，不提供跨重启恢复或完整历史导出。
- 密封竞拍仅公开提交状态，自己的报价仅本人可见；牌库只展示静态说明、待抽/弃牌/持有数量，不公开顺序或未选卡牌身份。

## 本轮核对与边界

类型检查和生产构建通过。本地预览核对了桌面/390px 窄屏布局、资产列表管理及返回、本人和旁观抽卡、道具界面，以及“自选骰子 → 购地 → 恢复原行动”的连续流程；未编写、修改或运行测试。多人真实对局、长时间网络中断和低性能手机仍需实际使用反馈。
