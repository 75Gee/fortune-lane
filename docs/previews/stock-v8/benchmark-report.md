# 股市 v8 · 50,000 次独立市场模拟

本轮吸收移动经营价值、随机景气、衰减趋势和项目概率定价。相比附件版本，降低周期/趋势/短期情绪强度；取消固定100元回归点和预设涨跌阶段。原股票名称及交易流程保留，每5个玩家交接更新一次。

## 方法

- 每支股票50,000条路径，每条70次行情，合计200,000条股票路径、350次玩家交接，报价从第1回合到第351回合。四股共享少量当期大盘冲击，不假设它们彼此独立。
- 固定正式种子2026291700～2026341699，Mulberry32。开发期5,000局种子2026391700～2026396699完全分开；参数在正式运行前固定。
- 调用游戏实际模型；没有另写模拟价格公式。模型与结算源码SHA-256保存在summary.json。
- 买入持有：每股100元时买100股，本金10,000元，70次行情后全卖；组合各股100股，总本金40,000元，不再平衡。这个股数使分币报价按整元结算时没有额外舍入误差。
- 策略也各自本金10,000元，仅整股、全仓/空仓切换，使用引擎实际买入向上取整、卖出向下取整；不加0.25%手续费、不借贷、不做空。
- 行情t公布后，用截至t的数据决定是否在t报价买卖，再经历t→t+1变动；终点只清仓。所有策略在同一路径配对比较，既不读取内部经营价值/趋势，也不读取未来报价。
- 没有模拟租金、购地、临时筹款或最终胜负。这是股市子系统的收益风险与简单择时检查。

## 结论与限制

- 买入持有存在少量正向增长，四股收益分散程度与最大回撤依次升高。事件股平均收益较高，但中位数为负，不能按平均值理解为大多数玩家赚钱。
- 本次测试的简单规则均未超过买入持有的平均收益，其配对差值95%区间也均低于0；没有复现附件所报告的约9%～12%机械策略平均收益。
- 这不意味着完全无法择时。空仓时间会减少经营增长，也可能减少风险；稳健股3期反向策略的盈利率高于持有，但平均收益更低。比较不同风险偏好时不能只看平均收益排名。
- 项目好消息策略平均收益约0.52%，没有因为成功概率公开而获得巨额收益。好消息公布时价格已经更新。
- 仍可能偶然大赚：事件股约4.82%的路径期末翻倍，约8.28%的路径亏损至少一半。它是高风险选择。
- 尚未覆盖最优状态估计、策略参数大规模搜索、动态跨股配置、不同局长及完整地产经济；不是无套利证明，也不保证全游戏平衡。均值置信区间未作多重策略比较校正。
