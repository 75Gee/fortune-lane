# Visual assets

The six city souvenir SVG player pieces under `tokens/` are original project artwork:
Beijing opera mask, Tokyo maneki-neko, Paris croissant, London double-decker bus,
New York yellow taxi, and Venice gondola.
`world-tour.svg` is original project artwork for the room setup and game board.

The four PNGs under `items/` are cropped from the user-provided four-panel artwork
`ChatGPT Image 2026年9月11日 14_08_45.png` (1254×1254). Each crop is 611×611,
with the panel border removed: turtle (top left), chosen die (top right),
roadblock (bottom left), and bomb (bottom right). The source image is unchanged.

The GLB files and preview sheet under `models/` are original project geometry,
exported from the same Three.js factories used on the board: supply kiosk,
Cairo courtyard, Hong Kong waterfront, and hospital.
