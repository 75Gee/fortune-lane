# 棋盘模型

六个模型与游戏共用几何和材质，采用GLB 2.0格式，无需外部贴图。Y轴向上，普通地标底座约3.2×3.2单位；医院为适配角落的L形三格底座，保留棋盘定位原点。路障和炸弹宽约1.4单位，直接放在棋盘格内。

| 模型 | 文件 | 场景用途 |
| --- | --- | --- |
| 旅途道具补给站 | [item-supply.glb](./item-supply.glb) | 南北两处补给站共用，棚亭、四种道具陈列与礼盒屋顶 |
| 开罗 · 金字塔庭院 | [cairo.glb](./cairo.glb) | 西侧新增地产：金字塔、狮身人面像、棕榈庭院 |
| 香港 · 维港建筑群 | [hong-kong.glb](./hong-kong.glb) | 东侧新增地产：玻璃塔楼、海滨步道、绿色渡轮 |
| 医院 · 旅途医疗中心 | [hospital.glb](./hospital.glb) | 替换原停车场，绿色医疗标识、门诊入口和救护车 |
| 路障 | [roadblock.glb](./roadblock.glb) | 所在格子展示橙白栏杆、双侧警示灯与落点环 |
| 炸弹 | [bomb.glb](./bomb.glb) | 所在格子展示圆形弹体、引线与火星；触发动画由游戏场景驱动 |

[六模型预览图](./preview.png)。地产升级建筑由游戏原有房屋与旅馆模块独立展示，GLB保留城市地标本体。

以上为项目内原创程序建模，保持现有棋盘的柔和配色、低多边形轮廓和小比例建筑细节。道具插画仍使用用户提供的四宫格裁剪素材。
